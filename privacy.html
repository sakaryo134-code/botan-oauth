プライバシーポリシー

このアプリケーション（以下「本ツール」）は、所有者本人が自分のYouTubeチャンネルを管理するための個人用ツールです。

取得する情報

本ツールは、所有者本人のOAuth認可に基づき、YouTube Data API を通じて所有者本人のチャンネル情報（チャンネルID・チャンネル名など）と、動画のアップロードに必要な情報のみを取り扱います。

情報の保管

認可トークンなどの認証情報は、所有者本人のPC内に、WindowsのDPAPIで暗号化して保存されます。外部のサーバーへ送信されることはありません。

第三者への提供

取得した情報を第三者へ販売・共有することはありません。

認可の取り消し

所有者は、Googleアカウントの「サードパーティによるアクセス」設定から、いつでも本ツールの認可を取り消すことができます。

Google APIの利用について

本ツールによる YouTube API サービスの利用は、YouTube利用規約および Google API サービスのユーザーデータに関するポリシーに準拠します。
